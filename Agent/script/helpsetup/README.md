# Help Setup Scripts

This folder contains the Windows helper scripts for bootstrapping and building the `Agent` project after the scripts were moved out of the project root.

## Files

- `setup_env.bat`
  - Detects the `Agent` project root automatically
  - Detects the DevEco Studio SDK automatically
  - Sets and persists:
    - `DEVECO_SDK_HOME`
    - `OHOS_NATIVE`
    - `OHOS_SDK_NATIVE`
    - `OHOS_NDK_HOME`
  - Generates `Agent\local.properties`
  - Ensures Rust OHOS targets are installed
  - Stops the hvigor daemon to avoid stale SDK cache

- `build.bat`
  - Calls `setup_env.bat`
  - Detects the `Agent` project root and repository root automatically
  - Locates the Rust workspace at `..\..\codex-main\codex-rs` relative to `Agent`
  - Clears project-local hvigor cache before build
  - Invokes the bundled DevEco hvigor entrypoint directly

## Expected Repository Layout

These scripts assume this structure:

```text
ArkPilot/
├─ Agent/
│  ├─ oh-package.json5
│  ├─ entry/
│  └─ script/helpsetup/
├─ codex-main/
│  └─ codex-rs/
```

The scripts do not require being run from the project root. They locate the `Agent` root by walking upward until they find:

- `oh-package.json5`
- `entry\build-profile.json5`

## Requirements

Before using the scripts on a new machine, install:

1. DevEco Studio with HarmonyOS/OpenHarmony SDK
2. Node.js
3. Rust and `rustup`

## Usage

Run from any terminal:

```bat
D:\code\harmony\ArkPilot\Agent\script\helpsetup\setup_env.bat
D:\code\harmony\ArkPilot\Agent\script\helpsetup\build.bat debug
```

Or from inside the script folder:

```bat
setup_env.bat
build.bat debug
build.bat release
build.bat clean
```

## Modes

- `build.bat debug`
  - Builds the unsigned debug HAP

- `build.bat release`
  - Runs release-mode build
  - A signed release artifact still depends on your project signing configuration

- `build.bat clean`
  - Removes:
    - `Agent\.hvigor`
    - `Agent\entry\build`
    - `Agent\entry\.cxx`

## Outputs

Debug output:

`Agent\entry\build\default\outputs\default\entry-default-unsigned.hap`

## Notes

- The scripts intentionally stop the hvigor daemon because stale daemon state previously cached an invalid old SDK path.
- `local.properties` is regenerated by `setup_env.bat`.
- If DevEco Studio is installed in a non-standard location, set `DEVECO_SDK_HOME` first, then rerun `setup_env.bat`.
