# 🧹 项目清理脚本

## 快速开始

### Windows
```cmd
# 快速清理（推荐日常使用）
clean.bat

# 高级清理（更多选项）
cleanup.bat
```

### Linux/macOS
```bash
# 添加执行权限
chmod +x clean.sh cleanup.sh

# 快速清理
./clean.sh

# 高级清理
./cleanup.sh
```

## 📁 清理内容

### 🔥 主要缓存（可安全删除）
- **`.cargo-target/`** - Rust 构建缓存（~27GB！）
- **`build/`** - 项目构建输出
- **`entry/build/`** - 模块构建输出
- **`.hvigor/`** - Hvigor 构建缓存
- **`.cxx/`** - C++ 构建缓存
- **`.clangd`** - ClangD 缓存文件

### ⚠️ 可选清理（谨慎操作）
- **`.idea/`** - IDE 配置（会丢失设置）
- **`oh_modules/`** - OpenHarmony 模块（需重新下载）
- **`node_modules/`** - Node.js 依赖（需重新安装）

## 🎯 使用场景

### 日常开发后清理
```bash
# 每天下班前运行，释放空间
./clean.sh
```

### 提交代码前检查
```bash
# 确保没有缓存文件被误提交
git status
git clean -n   # 查看将被删除的文件
```

### 磁盘空间不足时
```bash
# 深度清理所有缓存
./cleanup.sh
# 选择"深度模式"或"自定义模式"
```

### 重新构建项目前
```bash
# 清理旧构建，确保全新构建
./clean.sh
npm install
hvigor assembleHap
```

## 🚨 注意事项

1. **备份重要配置**：清理 `.idea/` 前导出 IDE 设置
2. **网络连接**：清理依赖目录后需要重新下载
3. **构建时间**：首次清理后构建会较慢
4. **Git 状态**：清理后运行 `git status` 检查

## 📝 最佳实践

1. **定期清理**：建议每周清理一次
2. **提交前检查**：确保 `.gitignore` 配置正确
3. **使用版本控制**：源代码必须提交到 Git
4. **选择性清理**：使用自定义模式按需清理

## 🆘 常见问题

### Q: 清理后项目无法构建？
```bash
# 重新安装依赖
npm install

# 重新构建
hvigor assembleHap
```

### Q: 误删了重要文件？
- 构建缓存：可安全删除，会重新生成
- 源代码：从 Git 恢复
- 配置文件：重新生成或从备份恢复

### Q: 如何只清理 Rust 缓存？
```bash
./cleanup.sh
# 选择"自定义模式"，只勾选 ".cargo-target"
```

### Q: 清理脚本安全吗？
- ✅ 只删除已知的缓存目录
- ✅ 不删除源代码
- ✅ 不删除配置文件（除 `.idea/`）
- ✅ 有确认提示
