# ArkPilot Agent 启动指南

## 项目概述

这是一个基于OpenHarmony的ArkTS应用项目，包含ArkTS前端和C++原生模块。

## 环境要求

### 1. 安装 DevEco Studio
- 下载并安装 [DevEco Studio](https://developer.harmonyos.com/cn/develop/deveco-studio)
- 确保安装OpenHarmony SDK（版本6.1.0）

### 2. 安装 Rust 工具链
项目包含Rust原生模块，需要安装：
- Rust (最新稳定版)
- OpenHarmony Rust target：
  ```bash
  rustup target add aarch64-unknown-linux-ohos
  rustup target add x86_64-unknown-linux-ohos
  ```

### 3. 配置环境变量
确保以下环境变量已设置：
- `OHOS_NATIVE`：指向OpenHarmony Native SDK路径
- `CARGO_HOME`：Rust cargo路径

## 启动步骤

### 方法一：使用 DevEco Studio（推荐）

1. **打开项目**
   - 启动 DevEco Studio
   - 选择 "Open" → 导航到 `D:\code\harmony\ArkPilot\Agent`
   - 等待项目同步完成

2. **配置签名**
   - 项目已包含调试签名配置
   - 如果需要重新生成签名，可以在 "File" → "Project Structure" → "Signing Configs" 中配置

3. **选择设备**
   - 在工具栏选择设备模拟器或连接真实设备
   - 支持ARM64和x86_64架构

4. **构建和运行**
   - 点击工具栏的 "Run" 按钮 (绿色三角形)
   - 或使用快捷键 `Shift+F10`

### 方法二：命令行构建

1. **安装 Hvigor 构建工具**
   ```bash
   npm install -g @ohos/hvigor
   ```

2. **构建项目**
   ```bash
   # 进入项目目录
   cd D:\code\harmony\ArkPilot\Agent
   
   # 构建调试版本
   hvigorw assembleHap
   
   # 构建发布版本
   hvigorw assembleHap --mode release
   ```

3. **安装到设备**
   ```bash
   # 安装hap包到设备
   hdc install entry/build/default/outputs/default/entry-default-unsigned.hap
   ```

### 方法三：使用预配置脚本

当前仓库已经拆分为“独立 native builder + 主应用消费预编译 so”模式：

1. **先构建并安装 native 模块**
   ```bash
   ..\libcodexhost-builder\build.bat debug x86_64
   ```

2. **再构建 Agent**
   ```bash
   script\helpsetup\build.bat debug
   ```

## 常见问题

### 1. 构建失败：缺少OpenHarmony SDK
- 确保DevEco Studio已正确安装
- 检查环境变量 `OHOS_NATIVE` 是否正确设置

### 2. Rust模块构建失败
- 确认Rust工具链已安装：`rustc --version`
- 确认OpenHarmony target已添加：`rustup target list | grep ohos`
- 检查 `libcodexhost-builder` 的 SDK/Rust 环境配置

### 3. 签名问题
- 调试版本使用自动生成的调试证书
- 发布版本需要申请正式签名证书

### 4. 设备连接问题
- 确保设备已开启开发者模式
- 使用 `hdc list targets` 检查设备连接状态

## 注意事项

1. **项目使用OpenHarmony API 10**
2. **需要HarmonyOS 6.1.0或更高版本**
3. **C++模块需要Rust工具链支持**
4. **建议使用DevEco Studio 4.1或更高版本**
